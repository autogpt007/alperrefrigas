
- MCP server: tools live in src/lib/mcp (one file each), use OAuth with caller-scoped client so RLS applies; supabase/functions/mcp is generated by mcpPlugin — never hand-edit.
- AI features call the Lovable AI Gateway SDK only from edge functions (never the browser); types are generated into src/generated/ai-gateway.
- RLS helper functions (is_admin, has_role) are evaluated inside public-read policies, so EXECUTE must be granted to every role those policies cover (including anon); otherwise every logged-out read on those tables fails with "permission denied for function is_admin".
- The checkout and shipping-calculator country list must mirror the active shipping_zones rows, so every country a buyer can pick resolves to a real freight zone instead of the Rest-of-World fallback.
